How it works

On most chains a contract runs only when someone sends a transaction. To react to a price, a deadline or an API, you run a bot that watches and submits. On Rialo a contract registers a predicate and the chain itself evaluates it at the end of every block; when it holds, the action runs in the next block. That is a reactive transaction.

In Reactor every rule is such a predicate. The world ticks block by block: feeds move, events happen, API calls return after a delay. Credits stand in for Stake for Service: each action and each API call spends some, and a rule with no credits left is skipped.

Switch on "Keeper bot" to run the same rules the old way: an offchain watcher that sees each block late and sometimes fails to land a transaction in congestion. The result sheet shows both.
